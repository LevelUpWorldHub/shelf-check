# User guide

Shelf Check is for a household that already decided what it wants to watch. The list might be a text file on the NAS or a photo of a note from the fridge. The films, if they were added to the video library, are already on the NAS.

Say something like: check the Friday list at this path, we start at 19:00 and we need to finish by 21:00.

You get one card. The four verdicts, one title, choose, blocked, and lookup not run, are illustrated in the shelf card note. Those illustrations are rule examples, not a NAS transcript. The card keeps your order. It tells you whether each readable title is in the library, whether the copies are the same bytes, and whether a known runtime fits the clock. If one title fits, the card names it. If several fit, it asks you to choose. If none fit, it says why. It does not offer a different film when yours is missing or when a line could not be read.

Nothing plays while the card is built. After you have read it, you can ask to save the card, to download one subtitle for one chosen file, or to play one chosen file. Each of those is a separate yes. If two copies differ, the card will not tell you which one to play.

Shelf Check does not build a recommendation, a poster, or a new library folder.
